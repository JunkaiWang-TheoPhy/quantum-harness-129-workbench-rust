# Complete Level 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify the complete #129 Level 0 path from PySCF-generated H2/H4 oracle artifacts to independently computed Rust dense-FCI energies.

**Architecture:** Python is an offline fixture generator only. Rust parses committed FCIDUMP data, enumerates determinants, applies the second-quantized Hamiltonian to build a transparent dense matrix, diagonalizes it, and verifies the result against committed JSON references.

**Tech Stack:** Rust 2024, `nalgebra`, `serde`/`serde_json`, `clap`, Python/PySCF in an isolated `.venv`.

## Global Constraints

- All electronic-structure algorithms and the normal CLI runtime are Rust.
- Python is allowed only under `scripts/oracle/` for independent oracle generation.
- Rust tests must pass without importing or executing PySCF.
- FCIDUMP uses one-based spatial indices and Mulliken `(pq|rs)` ordering.
- Level 0 fixture energy tolerance is `1e-10` hartree.
- Preserve complete oracle provenance and FCIDUMP SHA-256 checksums.
