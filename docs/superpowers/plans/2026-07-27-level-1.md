# Level 1 Direct FCI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement alpha/beta string direct FCI and Davidson, culminating in the frozen-core H2O/6-31G target.

**Architecture:** Lexical string link tables drive a matrix-free Hamiltonian operator. Davidson consumes an operator trait and a separately computed Hamiltonian diagonal; Level 0 dense matrices remain independent regression oracles.

**Tech Stack:** Rust 2024, nalgebra, serde; PySCF 2.14.0 offline fixtures.

## Global Constraints

- Never store the full H2O/6-31G Hamiltonian.
- Direct sigma must match dense `H*C` within `1e-11` on H2/H4 random vectors.
- Davidson must report both energy change and residual norm.
- Primary target uses H2O/6-31G canonical RHF orbitals with oxygen 1s frozen.

### Task 1: Electronic Problem and Active-Space Transformation

**Files:** Create `src/problem.rs`, `src/active_space.rs`; modify `src/fcidump.rs`.

**Interfaces:** Produce `ElectronicProblem` and
`freeze_core(problem, &[usize]) -> Result<ElectronicProblem, ActiveSpaceError>`.

- [ ] Add tests for integral dimensions, finite values, electron parity, and a
  hand-checkable one-orbital frozen-core transformation.
- [ ] Implement the validated problem type and frozen-core energy/one-body
  folding equations.
- [ ] Verify that zero frozen orbitals is an exact identity.
- [ ] Commit the active-space layer.

### Task 2: Lexical String Link Tables

**Files:** Create `src/strings.rs`.

**Interfaces:** Produce `StringSpace::new(norb, nelec)`, rank/unrank, and
`SingleExcitation { source, target, removed, added, sign }` links.

- [ ] Add exhaustive rank/unrank and link/sign tests through six orbitals.
- [ ] Implement combinadic lexical addressing and inverse addressing.
- [ ] Build links by fermionic annihilation/creation and target lookup.
- [ ] Compare links with Level 0 bit-operator results.
- [ ] Commit string addressing and links.

### Task 3: Matrix-Free Hamiltonian

**Files:** Create `src/operator.rs`, `src/direct_fci.rs`.

**Interfaces:** Produce trait
`LinearOperator { dimension, diagonal, apply(input, output) }` and
`DirectFciOperator`.

- [ ] Add deterministic random-vector tests comparing direct sigma and dense
  multiplication for H2/H4.
- [ ] Implement alpha, beta, and mixed-spin contractions from link tables.
- [ ] Implement the diagonal without constructing the matrix.
- [ ] Verify Hermiticity through bilinear products `<x|Hy>=<Hx|y>`.
- [ ] Commit direct sigma.

### Task 4: Davidson Solver

**Files:** Create `src/davidson.rs`.

**Interfaces:** Produce `DavidsonConfig`, `DavidsonResult`, and
`lowest_eigenpair(&impl LinearOperator, initial, config)`.

- [ ] Add diagonal-matrix, clustered-eigenvalue, restart, non-convergence, and
  H2/H4 regression tests.
- [ ] Implement orthonormal expansion, Ritz extraction, residual
  preconditioning, and thick restart.
- [ ] Verify residual norm independently from the returned result.
- [ ] Commit Davidson.
