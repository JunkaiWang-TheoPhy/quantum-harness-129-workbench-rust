# Level 4 Direct-Integral Stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a direct Rust libcint → RHF → AO-to-MO → FCI path and verify it against PySCF.

**Architecture:** A feature-gated libcint frontend produces AO integrals in a validated molecule model. RHF and AO-to-MO are library-owned Rust algorithms that output the same `ElectronicProblem` used by Levels 0–3.

**Tech Stack:** Rust 2024, libcint crate, nalgebra, shared DIIS.

## Global Constraints

- PySCF is a cross-check, never a runtime dependency.
- AO memory order and integral convention are explicit at every boundary.
- H2 and H2O/STO-3G must complete the full direct path.
